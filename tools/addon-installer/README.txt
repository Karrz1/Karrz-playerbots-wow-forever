ForeverBots add-on installer
============================
Double-click Install-Addon.cmd. It finds your WoW Forever game folder (the one with the file .build.info; it asks you to confirm),
copies the ForeverBots add-on into <game folder>\_classic_beta_\Interface\AddOns, and tells you what to tick in the game.
Run it again after a new release to refresh the add-on. No administrator rights are needed, and it does not touch any server.

By hand instead: put the folder ForeverBots into <game folder>\_classic_beta_\Interface\AddOns so that
...\AddOns\ForeverBots\ForeverBots.toc exists.
