WoW Forever Bots 0.1.9 (client 70450, Zul'Gurub, Ahn'Qiraj ruins, world events)

Matches the main realm build and moves to the newest game client. **You need the WoW Forever client build 70450** (1.60.1.70450); an older client is refused at login.

**Client and update**
- Realm and installer now use client build 70450. Copy the new client folder (do not let Battle.net patch the copy), then update.
- After the first database update, restart bnetserver (menu: Stop, then Start) so it picks up the new realm build. The Start button in the menu already starts it after the world server.
- Includes advocaite's latest Forever changes (client 70425 and 70450 data).

**Raids and dungeons**
- Molten Core: fight scripts for Geddon, Garr, Shazzrah, Golemagg and Sulfuron; Flamewaker Priests heal.
- Blackwing Lair: Nefarian's phase 3 raises Bone Constructs, trash at vanilla density.
- Zul'Gurub: Arlokk appears after the gong; Thekal, Lor'Khan and Zath feign death and Thekal rises as a tiger. Ruins of Ahn'Qiraj: General Rajaxx's waves and Andorov. Raid rules for ZG, AQ20, BWL, AQ40 and Naxxramas.
- Scholomance and Lower Blackrock Spire event fixes, Naxxramas Thaddius, AQ40 Obsidian Eradicator, Horde Onyxia attunement.
- A dungeon or raid that is full no longer gets more bots invited than it holds.

**World**
- The vanilla event calendar (holidays, seasonal quests, Pyrewood worgen night, Booty Bay New Year) and the Great Masquerade in Stormwind.
- A core roster of world bots plus a variable pool that is created around players and removed when unused.
- More checked walking links between parts of the map; bots remember walks that failed.
- The auction house bot is on by default, for installs and for server builds.

**Bots and add-on**
- Every account can use the commands for its own bots. Lazy lock: one key casts the next warlock spell on your target (add-on 0.2.4, also a separate download).
- Power Word: Shield and the mage wards scale with spell power again.

**Install and update**
- Update from an earlier release with the Update button (menu U). To install: download WoW-Forever-Bots-0.1.9.zip, unzip it into a folder without spaces in its path (for example C:\WoWForever) and double-click Install.cmd. wow-forever-update-0.1.9.zip is what the Update button downloads. wow-forever-source-0.1.9.zip is the complete source (GPL v2).
